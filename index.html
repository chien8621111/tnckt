Gõ yêu cầu bằng tiếng Việt, Claude vẽ lên bản vẽ AutoCAD của bạn

AcadClaude là add-in cho AutoCAD 2021–2024. Bạn mô tả việc cần làm trong khung chat, Claude đọc bản vẽ đang mở rồi tạo layer, vẽ lưới trục, đặt cột, ghi chú. Mỗi thao tác vẫn hoàn tác được bằng lệnh U như bình thường.

Tải bản cho AutoCAD 2022 Xem cách cài đặt

Phần chat cần Anthropic API key. Các nút trên ribbon dùng được không cần key.

ABa cách làm việc với bản vẽ

Chat ngay trong AutoCAD

Gõ CLAUDE để mở palette. Claude dùng các tool đọc và vẽ trên bản vẽ đang mở, và mỗi lần gọi tool đều hiện trong khung chat để bạn theo dõi.

“Đếm số polyline trên layer S-COLS”

Tab ribbon Kết Cấu

Các lệnh vẽ nhanh không cần AI: lưới trục có bubble và dim, cột tại giao trục, bộ layer chuẩn, đếm đối tượng, cộng diện tích.

Bước trục nhập kiểu 3*6000,8000

Điều khiển từ Claude Desktop

Bật cổng MCP để Claude Desktop hoặc Claude Code dùng chung bộ tool, làm việc với AutoCAD ngay từ cửa sổ chat quen thuộc.

Tool mới viết trong add-in tự xuất hiện

Bạn luôn là người quyết định

  • Claude mô tả và chờ bạn xác nhận trước khi xóa đối tượng.
  • Mỗi lần gọi tool là một bước Undo riêng, gõ U để quay lại.
  • Chỉ nội dung bạn chat và kết quả của tool (tên layer, tọa độ, text) được gửi tới Anthropic API. File bản vẽ không bị tải lên.

CDùng AutoCAD từ Claude Desktop

App nhỏ AcadMcpBridge.exe nối Claude Desktop với add-in đang chạy trong AutoCAD. Cổng chỉ mở trên máy của bạn và có token bảo vệ.

  1. Claude DesktopBạn gõ yêu cầu
  2. AcadMcpBridge.exeChuyển yêu cầu qua localhost:8765
  3. AutoCAD + AcadClaudeChạy tool trên bản vẽ đang mở

Thêm vào claude_desktop_config.json (Settings, Developer, Edit Config), sửa đường dẫn cho đúng máy bạn:

{
  "mcpServers": {
    "autocad": {
      "command": "D:\\AI CAD\\AcadMcpBridge\\AcadMcpBridge.exe"
    }
  }
}

Dùng Claude Code thì chỉ cần một lệnh:

claude mcp add autocad -- "D:\AI CAD\AcadMcpBridge\AcadMcpBridge.exe"

DCài đặt trong 5 bước

  1. Tải và giải nén

    Chuột phải vào file zip, chọn Properties, tích Unblock rồi mới giải nén. Nếu bỏ qua bước này, Windows sẽ chặn DLL và AutoCAD không nạp được.

  2. Nạp vào AutoCAD

    Mở AutoCAD, gõ NETLOAD rồi chọn AcadClaude.dll. Các file System.*.dll đi kèm phải nằm cùng thư mục.

  3. Nhập API key

    Tạo key tại console.anthropic.com, sau đó gõ CLAUDEKEY và dán key vào. Bước này chỉ làm một lần.

  4. Mở palette và thử

    Gõ CLAUDE. Ở tab Tools, chạy thử get_drawing_info. Ở tab Chat, gõ một yêu cầu bất kỳ.

  5. Tự nạp khi mở AutoCAD

    Chép thư mục AcadClaude.bundle vào %APPDATA%\Autodesk\ApplicationPlugins\ để khỏi phải NETLOAD mỗi lần.

Sắp có

FHỏi đáp

Dùng có mất phí không?

Add-in miễn phí. Phần chat gọi Anthropic API, tính phí theo lượng dùng trên tài khoản API của bạn và tách biệt với gói Claude.ai Pro/Max. Bấm “Hội thoại mới” khi chuyển việc để tiết kiệm.

File bản vẽ của tôi có bị gửi lên mạng không?

Không. Chỉ câu bạn chat và kết quả mà tool trả về (tên layer, tọa độ, nội dung text) được gửi tới Anthropic API. Với bản vẽ có yêu cầu bảo mật của chủ đầu tư, hãy cân nhắc trước khi dùng phần chat.

Chữ tiếng Việt hiện thành dấu hỏi

Text style đang dùng font .shx. Bấm nút Font tiếng Việt trên tab Kết Cấu (lệnh AC_FONTVN) để đổi sang Arial.

NETLOAD báo “Cannot load assembly”

File bị Windows chặn. Unblock file zip, giải nén lại, rồi NETLOAD lần nữa.

Tôi có tự viết thêm lệnh được không?

Được. Mỗi lệnh là một hàm C#. Gắn thêm [RibbonButton] thì lệnh có nút trên ribbon, viết class kế thừa ToolBase thì Claude dùng được ngay. Xem file README trong mã nguồn.
